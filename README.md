# Password Generator

## Project Description

This is a Password Generator application developed using Python.

The application generates strong random passwords based on the length entered by the user.

## Features

- Generate random passwords
- Supports uppercase letters
- Supports lowercase letters
- Supports numbers
- Supports special characters
- Minimum password length validation
- Maximum password length validation
- Invalid input handling
- Randomizes password characters

## Technologies Used

- Python
- Random module
- VS Code

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python password_generator.py
